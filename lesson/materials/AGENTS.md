# Проект «Трекер задач»

## Что это

Консольное приложение на Python: список задач хранится в `tasks.json`,
меню и логика — в `tracker.py`. Интерфейс и данные — на русском языке.

## Правила

- Только стандартная библиотека Python. Никаких `pip install`.
- Python 3.8: не использовать `match`, `list[str]`, `int | None`.
- Не менять формат `tasks.json` без отдельной задачи.
- Новые функции — с docstring на русском.
- После изменений запускать `python3 tracker.py` и проверять меню.
- Не удалять и не перезаписывать `tasks.json` без подтверждения.
- В отчётах сначала числа, потом вывод.

## Проверка

- Сумма задач по статусам равна общему числу задач.
- Старые записи в `tasks.json` продолжают читаться.
- Код работает на Python 3.8.
